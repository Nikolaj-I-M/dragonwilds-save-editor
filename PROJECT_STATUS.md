# Dragonwilds Save Editor

Local editor for RuneScape: Dragonwilds character saves.

Current support:

- Umbral Sands (game version 0.12 catalog)
- Action bar, bag, runes, ammo, and quest inventories
- Direct local save read/write on `localhost`, with a timestamped backup before each write

Run locally:

```powershell
npm.cmd run dev
```

Then open `http://localhost:3000`.
